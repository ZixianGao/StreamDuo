# StreamDuo project page

Static project page for *StreamDuo: A Live Commentator and a Research Agent for Unseen Games*.
Open `index.html` in a browser, or serve this folder with any static host.

- `static/img`: paper figures and gameplay frames
- `static/video`: promo video and poster
- `static/icons`: Microsoft Fluent Emoji 3D (MIT, see the license file)
- `static/fonts`: Inter (OFL) and P052

Results on the page are preliminary and live in the `MODELS` array in `index.html`.
